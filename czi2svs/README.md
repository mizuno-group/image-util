## CZI to Pyramidal TIFF Converter


## Installation
```
# Update package list
sudo apt update

# Install libvips and its dependencies
sudo apt install -y libvips-dev

# Install required Python packages
pip install pyvips aicspylibczi numpy
```

Usage
```
python czi2svs.py ./input/sample.czi ./output/sample.tif
```
